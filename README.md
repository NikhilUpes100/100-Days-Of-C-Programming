## ⚙️ How to Run the Programs

Follow these steps to run any C program.

**Step 1: Clone the repository**

```bash
git clone https://github.com/NikhilUpes100/100-Days-Of-C-Programming.git
```

**Step 2: Open the repository**

```bash
cd 100-Days-Of-C-Programming
```

**Step 3: Navigate to a particular day**

```bash
cd Day-01
```

**Step 4: Compile the C program**

```bash
gcc filename.c -o output
```

**Step 5: Execute the program**

```bash
./output
```

Replace `filename.c` with the name of the program you want to execute.
